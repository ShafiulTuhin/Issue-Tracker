🌟 GitHub Issue Tracker (Vanilla JS)

Overview:
This is a fast and intuitive GitHub Issue Tracker built purely with vanilla JavaScript, HTML, and CSS. It allows users to connect to any public GitHub repository, fetch its issues, and interact with them in a clean, responsive interface. Designed for simplicity and efficiency, this project highlights API integration, dynamic UI updates, and practical JavaScript skills.

Key Features:

Fetch GitHub Issues: Instantly load issues from any public repository.
Filter & Search: Easily filter issues by status (open/closed) or search by keywords.
Dynamic Updates: All issue data updates live without reloading the page.
Responsive Design: Optimized for desktops, tablets, and mobile devices.
Vanilla JS Implementation: Pure JavaScript solution—no frameworks or libraries.

Why This Project:
This project is perfect for developers learning API usage, DOM manipulation, and modular JS coding while building a real-world, functional tool. It’s also a great showcase for your portfolio demonstrating frontend fundamentals and problem-solving skills.
